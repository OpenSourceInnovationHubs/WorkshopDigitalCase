# Digital Workshop Case for IoT JSON

This application is a browser-based interactive playground for modeling simple energy systems. Users can visually compose and configure elements such as houses, photovoltaic (PV) roofs, batteries, and grid connections using drag-and-drop interactions.

It is particularly suited for workshops, demos, and educational use cases around smart energy and FIWARE ecosystems.

## Features:

- Export blueprints as JSON
- Import custom blueprints via drag & drop
- Apply new defaults to future element
